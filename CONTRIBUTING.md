# Contributing / 参与公开仓库

Stardew Valley Mod Manager is **closed-source, proprietary software**. The complete application source code is not published in this repository, so source-code pull requests for the application are not accepted here.

Stardew Valley Mod Manager 是**闭源、专有软件**。完整应用源代码不在本公开仓库发布，因此本仓库不接受针对应用源码的 Pull Request。

You can still help by:

- reporting reproducible bugs through [GitHub Issues](https://github.com/XModLife/Stardew-Valley-Mod-Manager/issues);
- providing macOS compatibility information, especially physical-Intel or older-system results;
- correcting documentation errors;
- improving Simplified Chinese or English documentation;
- proposing and reviewing translations for additional interface/documentation languages;
- reporting broken links or release instructions;
- proposing focused features with a clear use case.

你仍可以通过以下方式参与：

- 提交可复现 Bug；
- 补充 macOS 兼容性信息，尤其是 Intel 实机或旧系统测试结果；
- 修正文档错误；
- 改进简体中文或 English 文档；
- 提议并协助审核其他界面/文档语言；
- 报告失效链接或发布说明问题；
- 提交具有明确使用场景的功能建议。

## Language contributions / 语言贡献

SVMM currently ships developer-maintained Simplified Chinese and English localizations. Its localization/String Catalog architecture leaves room for additional languages.

SVMM 当前由开发者正式维护简体中文和 English，本地化 / String Catalog 架构保留继续增加其他语言的空间。

The developer cannot responsibly validate a language they do not understand. A proposal for another language should therefore have at least one fluent contributor who can translate, proofread, and help review later UI changes.

开发者不会把自己无法理解和审核的语言直接视为官方完整支持。因此新增语言最好至少有一名能够实际使用该语言的贡献者负责翻译、校对，并在后续界面变化时协助复核。

Before doing a large translation, please open an Issue or contact **SVMM@npccare.cn** so scope, terminology, maintenance expectations, and file format can be agreed first.

在进行大规模翻译前，请先通过 Issue 或 **SVMM@npccare.cn** 联系，以便确认范围、术语、后续维护方式和文件格式。

Documentation-only pull requests may be reviewed at the developer's discretion. Acceptance of documentation or localization contributions does not make SVMM open source.
