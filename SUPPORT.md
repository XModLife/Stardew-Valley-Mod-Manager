# Support & Issue Reporting / 支持与问题反馈

For ordinary bugs, compatibility reports, documentation problems, and focused feature requests, use:

**[GitHub Issues](https://github.com/XModLife/Stardew-Valley-Mod-Manager/issues)**

普通 Bug、兼容性问题、文档错误和明确的功能建议，请使用：

**[GitHub Issues](https://github.com/XModLife/Stardew-Valley-Mod-Manager/issues)**

## Include / 建议提供

- SVMM version / SVMM 版本
- macOS version / macOS 版本
- Mac model and chip/architecture (`arm64` / `x86_64`) / Mac 型号与芯片架构
- physical Mac or virtual machine / 物理 Mac 或虚拟机
- Stardew Valley version / Stardew Valley 版本
- SMAPI version, when relevant / 与问题相关时提供 SMAPI 版本
- Nexus Mods: disconnected / Free / Premium, when relevant / 与问题相关时说明 Nexus Mods 状态
- expected behavior / 预期行为
- actual behavior / 实际行为
- reproduction steps / 复现步骤
- affected Mod name, version, and Unique ID, when relevant / 与问题相关时提供 Mod 名称、版本和 Unique ID

For performance reports, describe whether the delay occurs on first entry, after scanning, after enabling/disabling a Mod, during selection, or during another specific operation.

性能问题请尽量说明延迟发生在首次进入、扫描后、启用/停用 Mod 后、行选择时，还是其他明确操作中。

## Do not post secrets / 不要公开秘密信息

Do not post Nexus API Keys, passwords, tokens, payment credentials, or other authentication secrets.

不要在公开 Issue、截图或日志中提交 Nexus API Key、密码、Token、支付凭据或其他认证秘密。

Review screenshots and local file paths before posting; they may reveal macOS usernames or other private information.

提交前请检查截图和本地文件路径，其中可能包含 macOS 用户名或其他不希望公开的信息。

## Language collaboration / 语言协作

SVMM currently maintains Simplified Chinese and English interface localizations. The localization architecture can accommodate additional languages, but the developer cannot independently review languages they do not know.

SVMM 当前正式维护简体中文和 English。架构可以继续扩展语言，但开发者无法独立审核自己不掌握的语言。

If you can provide fluent translation and review for another language and are willing to help maintain it as the UI evolves, open an Issue or contact the developer.

如果你能够为其他语言提供可靠的翻译、校对，并愿意在界面变化后继续协助维护，可通过 Issue 或邮件联系。

## Security / 安全问题

Do not use a public Issue for an unpatched security vulnerability. Follow [SECURITY.md](SECURITY.md).

未修复的安全漏洞不要直接提交公开 Issue，请按照 [SECURITY.md](SECURITY.md) 私下报告。
